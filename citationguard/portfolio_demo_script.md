# CitationGuard 演示脚本

## 演示目标

在 3～5 分钟内展示“上传文献 → 检查论文句子 → 查看证据 → 回看历史”的完整闭环。

## 演示准备

准备 2～3 篇公开论文 PDF，以及一段包含以下三类句子的示例文本：

1. 文献明确支持的句子。
2. 文献只支持一部分、但论文措辞过强的句子。
3. 没有足够引用支持的句子。

## 演示步骤

1. 输入内测访问密钥，展示有效期和工作区隔离。
2. 上传两篇参考文献，展示标题、页数和解析完成状态。
3. 粘贴示例论文段落。
4. 点击“识别并确认引用映射”。
5. 点击“开始引用准确性检查”。
6. 展示 PASS/CHECK/RISK/FAIL 四类结果。
7. 打开一条 RISK 结果，说明系统给出了证据片段、风险原因和建议改法。
8. 打开“我的历史”，点击一篇文献查看解析正文，再打开一次历史检查查看论文内容。
9. 最后说明模型分工：本地解析和检索负责缩小范围，Qwen负责主张和判断，DeepSeek只复核高风险结果。

## 演示时不要承诺

- 不要说系统可以替代导师、审稿人或领域专家。
- 不要把“模型判断”说成“事实证明”。
- 不要在公开演示中上传真实未发表论文或真实 API Key。
